# Digital Library System

##  Description
A simple console-based Java application to manage books, borrowers, and borrowing processes in a digital library using Object-Oriented Programming.


## How to Run

1. Compile the project:
```
javac -d bin src/library/*.java
```

2. Run the application:
```
java -cp bin library.LibraryApp
```

## Features
- Add Books (Paper or EBook)
- Add Borrowers
- Borrow and Return Books
- Search for Books and Borrowers
- View Borrowed Books

## Structure
- `src/`: Source code
- `docs/`: Documentation
- `tests/`: Unit tests
